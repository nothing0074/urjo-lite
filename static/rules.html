Rules

Goal: fill every empty spot with either red (X) or blue (O).

  • Row balance: each row has the same number of X and O spots.
  • Adjacent rows differ: no two neighbouring rows use the same pattern.
  • Number clue: a spot showing N means exactly N of its 8 surrounding spots share its color.
  • Given spots (grey) are already filled and cannot be changed.

How to play: pick a color with the X / O button, then tap an empty spot. A correct fill is kept; a wrong tap counts as one mistake (each spot can only be mistaken once). Finish the grid to solve the puzzle.

Scoring: your rating updates from solve time and mistakes. Faster and cleaner solves rank higher on the Top page.
